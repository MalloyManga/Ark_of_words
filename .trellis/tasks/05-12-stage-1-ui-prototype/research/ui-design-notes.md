# UI Design Notes

- Primary direction: bright emerald/green, eye-comfort, learning-tool rather than school/education portal.
- Hero pattern: left text/actions, right character visual with a typewriter overlay.
- Use clear hierarchy, generous whitespace, stable button dimensions, and readable contrast.
- Avoid making the first screen a marketing landing page with unrelated sections; the UI should feel like the actual app entry point.
- Avoid emoji-as-icons in interactive controls. Use text-only buttons for this prototype unless an icon library already exists.
